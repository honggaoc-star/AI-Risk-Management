# Return Weighted Risk for Navigating an Evolving AI Landscape

This directory is the home of a research initiative within AI Risk Management.

The project recognizes that organizations increasingly deploy AI before they fully understand either the value an activity will ultimately create or the risks it will ultimately generate. It proposes Return-Weighted Risk (RWR) as an activity-level governance approach that keeps the value case connected to an independently assessed risk case as both evolve.
